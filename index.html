    Sir Edwards Quiz

    Test de Lucidez Mental · v1.3

    Un quiz de cultura general con varios modos de juego, logros por desbloquear y un modo Duelo para retar a tus amigos con el mismo set de preguntas. Todo tu progreso se guarda únicamente en este dispositivo.

    ⚔️ ¿Cómo funciona un Duelo?

    1. Crea un reto
    Elige un modo y juega tu partida.

    2. Genera el código
    Al terminar la partida, se genera un código para ese reto.

    3. Comparte el código
    Envíalo a tu rival. Él lo introduce y juega la misma partida.

    4. Compara el resultado
    Gana quien consiga la mayor puntuación.
